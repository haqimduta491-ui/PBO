# Program Perpustakaan Sederhana

Program ini merupakan aplikasi perpustakaan sederhana berbasis Java yang digunakan untuk menyimpan dan menampilkan informasi buku.

Program memiliki fitur untuk menampilkan data buku seperti judul, penulis, kode buku, serta status ketersediaan buku. Program juga menyediakan fitur peminjaman buku dan menggunakan konsep dasar pemrograman Java seperti Class & Object, Constructor, Constant, Conditional, Looping, Exception Handling, String, Character, dan ArrayList.

Program ini dibuat sebagai implementasi materi dasar Pemrograman Berorientasi Objek (PBO).
